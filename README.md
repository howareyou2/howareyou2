## Projects

### 🥐 빵별일지
빵집 탐색·코스 계획·방문 기록 앱

사용자 행동에 따른 제품 개선과 **OpenSearch 검색 품질 개선**,  
**Spring Batch·Kafka 데이터 최신화** 및 이미지 결손·운영 장애 대응을 맡았습니다.

### 👓 [내눈N](https://github.com/howareyou2/nenoonM) · Private
안경원 업무를 모바일로 연결하는 기업 연계 프로젝트

대표·점주와 요구를 조율하고, **접속 상태별 채팅·푸시 전달 분리**와  
MongoDB 메시지 저장·Kafka 연동을 담당했습니다.

### 💰 [머니위즈](https://github.com/howareyou2/moneyWizz)
초등학생을 위한 경제교육 서비스

**외부 금융망 가입 성공·내부 저장 실패 시 복구**와  
교육 자료 기반 **RAG 챗봇 제안·구현**을 담당했습니다.

### 🎙️ [DubDub](https://github.com/howareyou2/dubdub)
실시간 더빙·공동 편집 서비스

**Redis 편집권·버전 검사**와 편집 동기화 오류를 다루고,  
인프라·배포 구축과 스크럼 운영을 맡았습니다.
