## Tech Stack

프로젝트에서 사용한 기술과 활용 경험입니다.

| 영역 | 기술 | 활용 경험 |
| --- | --- | --- |
| **Backend** | Java · Spring Boot · Python · FastAPI | 서비스 API, 채팅·챗봇 서버 |
| **Data & Search** | PostgreSQL · MySQL · MongoDB · OpenSearch | 업무 데이터, 방별 메시지 저장, 한글 검색·자동완성·검색 순위 |
| **Batch & Messaging** | Spring Batch · Kafka · RabbitMQ | 데이터 수집·갱신, 채팅·알림 처리 분리, 편집 이벤트 전달 |
| **Concurrency** | Redis | 만료 편집권·버전 검사, 공동 편집 상태와 접속 관리 |
| **Infrastructure** | AWS EC2 · ALB · S3 · Lambda / Docker · Nginx | 서비스 배포, 트래픽 연결, 이미지 처리·복구 |
| **CI/CD & Monitoring** | GitHub Actions · Jenkins · Prometheus · Grafana | 배포 자동화, 실행 상태·메트릭 관측과 장애 추적 |
